# CustomATM 1.2.2 - Multiplayer join workaround

The host log showed PneumaticCraft failing to encode `pneumaticcraft:sync_amadron_offers` because a cached Advanced Peripherals pocket-upgrade holder was not in the current registry. This disconnects remote players while leaving the host connected.

This patch sets Amadron's random villager-offer count to zero in memory during recipe loading. Amadron keeps its normal recipe offers and player offers. Normal villagers, Advanced Peripherals, ComputerCraft, and PneumaticCraft remain installed and usable. The temporary trade-import workaround can be removed once an upstream fix is available.

Both players must fully close Minecraft, run **Update CustomATM**, and relaunch. The host then opens the world and invites the friend again. Returning to the title screen is not a full restart.

Validation: checked the installed mod's active-offer selection and packet serialization paths; verified the script with the installed Rhino engine using typed config fixtures. A successful two-player reconnect still needs to be confirmed in game.

Related report: https://github.com/FTBTeam/FTB-Modpack-Issues/issues/12982
