# CustomATM 1.4.0 — Redstone Arcade

The casino hub and all eight games now use the selected Minecraft-style Redstone Arcade design: stone/copper frames, emerald controls, pixel artwork and a shared DynEco wallet display.

- Redesigned Slots, Coin Flip, Mines, Blackjack, Roulette, Plinko, Scratch Ticket and Crash.
- Clear bet controls, rules/paytables, total returns and net results.
- Interactive Mines grid, Blackjack hands and Hit/Stand/Double, full Roulette betting table, Plinko risk levels and server-result animation, scratch click/drag reveal, and Crash multiplier/cash-out.
- Active rounds and pending results remain available when reopening the casino during the same connection. Closing Crash does not pause or automatically cash out.
- Prevents duplicate wagers, hidden inventory-slot clicks and closely timed result messages overwriting one another. Corrects Blackjack's displayed payout field.

## Update

Both players must fully close Minecraft, run **Update CustomATM** (or the profile's **Update Pack.cmd**), and wait for **Ready: CustomATM 1.4.0**. Then launch CustomATM and open the casino with **F8** in a world.

If you already updated successfully to 1.3.0, your existing shortcut works: **no new ZIP download is needed**. If an old updater reports “Unsupported update format,” download and extract this release's **CustomATM-Setup.zip** once and run its **Update Pack.cmd**; it reuses your existing profile.

This release adds only `customatm-arcade-0.2.0.jar` to the verified 1.3.0 content. Existing quests, economy prices, game odds/payouts and other mods are unchanged. Saves and personal data are outside the managed update.

## Validation

Native addon compiled against the pinned Minecraft/NeoForge/Gamble It versions. Offline checks passed: 100,359 Coin Flip assertions, 910 additional game protocol/input assertions, 59 screen-state renders, package checks, screen/mixin-target inspection, updater transaction tests and an isolated 1.3.0-to-1.4.0 addon installation.

Minecraft was not launched during preparation. In-game rendering, mixin application, live wallet flow and Essential multiplayer still need a playtest. The UI redesign does not rebalance the existing game paytables.
