# CustomATM 1.3.0 — quest workshops and farm-aware economy

## Quest overhaul

- Rebuilds all ten custom chapters around 38 named branches and 269 quests, including 60 new workshops and 224 item milestones.
- Adds ten original setup diagrams, branch headers, small XP rewards, real equipment goals and Moon/Mars/Glacio visit checks.
- Expands machine configuration, resource loops, progression, troubleshooting and practical examples. Covers the installed Astral port, Ender IO conduit variants, RS addons, colony delivery, SFM/XNet automation, ComputerCraft and RFTools.
- Keeps all original chapter and quest IDs. Item tasks do not consume materials. Normal equipment milestones detect items automatically; final projects keep their practical confirmation. New objectives may need additional items.
- Casino quests remain optional, with no wins or repeated bets required. The default key is F8.

## Economy

- Reprices 64,236 reported items/fluids with renewable resource generation in mind. Cobble base value is $0.01; a diamond pickaxe is about $352.02 before spread and demand.
- Adds persistent per-player buyer allowances shared across listings, linked chests and tanks. Sustained sales target up to $10,000 per online hour; bulk/farming/resources recover $500/$1,500/$4,000 within that total. Unused demand can accumulate for one hour.
- Adds `/marketlimits`. Sale amounts are bounded before extraction, offline selling pauses and reconnecting does not reset allowances. Existing wallet money is preserved.
- Expensive goods keep their retail value but have per-item/bucket buyback ceilings of $250/$750/$2,000/$5,000 by category. Inspect the sell quote before offering valuable compressed items.
- Adjusts prices immediately after sales and applies verified compressed-block ratios plus explicit values for important endgame items.

## Install later

Both players fully close Minecraft, **download and extract this release's CustomATM-Setup.zip once**, then run its **Update Pack.cmd**. It reuses the existing CustomATM profile and refreshes the shortcut. Launch **CustomATM** through CurseForge afterward.

This release requires updater version 4. FTB rewrites quest definitions when saving; the old updater mistakes that rewrite for a personal edit. Version 4 accepts only exact, verified rewrite hashes tied to the previously installed version. Unknown personal edits are still protected. Old shortcuts will tell you to download the new Setup ZIP.

The running host profile was not modified while preparing this release. Saves and saved quest progress are not included in the payload.

## Validation and limits

Passed: all 55 updater checks, a read-only upgrade plan against the existing profile, quest graph/ID/item/asset/layout checks, all 20 quest files through Minecraft and FTB SNBT parsers, catalogue tests, addon compilation, 230,400 simulated allowance attempts, and all nine sale-path hooks inspected in previously exported transformed bytecode. Release payload hashes are verified on build and upload.

No Minecraft client/server was launched for this release while the host was playing. Full in-game UI, sales and friend-join testing remains pending. The earlier minimal economy probe stopped on an unavailable compressed-item test fixture after the initial assertions; the fixture is corrected but the full runtime rerun is still outstanding. Treat the pricing as a first automation-aware balance pass, not a claim that every individual machine price has been manually playtested.
