# CustomATM 1.1.0

Extract the latest **CustomATM-Setup.zip** and run **Update Pack.cmd**. Setup now creates a separate **CustomATM** tile in CurseForge Standalone and installs the pinned ATM10 8.3 base automatically. A preinstalled ATM10 profile is no longer required.

- Creates the Minecraft 1.21.1 / NeoForge 21.1.259 profile through CurseForge's local service.
- Downloads the official ATM10 archive with a pinned checksum, installs its base configs/quests/recipes and original shaders, then applies the complete CustomATM mod manifest.
- Reuses verified installed jars to save downloads. Downloads missing jars from their original hosts.
- Repeated setup updates the same profile. Interrupted base setup resumes without creating a duplicate.
- Creates/retargets the Update CustomATM desktop shortcut and preserves other profiles and worlds.
- New profiles use the official base's recommended 8196 MB allocation; later memory changes are preserved.

**Upgrade from 1.0.x:** download and extract this new Setup ZIP once. Running it creates the new separate profile; the old customized ATM10 profile and its worlds remain available. The old updater will request the newer Setup. Future updates use the installed shortcut.

Requires Windows 10/11 and CurseForge **Standalone**, with Minecraft setup completed in the app once. The Overwolf edition is not supported by this bootstrap. No GitHub account, Git, Python, or manual ATM10 installation is needed. Keep CurseForge open until setup finishes.

Validation: 64 Windows PowerShell 5.1 updater and bootstrap checks cover transactions/recovery, clean installation without an existing base, duplicate prevention, interrupted setup, receipt identity, checksum failures, archive traversal and verified cache reuse. A real separate profile was created through CurseForge and populated with all 504 mods; repeated setup reported zero pack changes and reused the same GUID. Full in-game and multiplayer testing is still pending.
