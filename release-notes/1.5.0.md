# CustomATM 1.5.0 — Ballistix

Adds **Ballistix 1.21.1-1.2.3** and its required **Voltaic 1.21.1-1.2.0** library for missiles, launchers, radar and defensive turrets. Uses the author's original CurseForge downloads; no third-party jars are redistributed in our overlay. Electrodynamics is optional and is not added; the pinned Ballistix jar includes recipes for play without it.

Nuclear, antimatter, large-antimatter and dark-matter explosives, including their minecart forms, are excluded from crafting and DynEco trading. Conventional warheads and missile defenses remain available. This limits survival acquisition; it is not a creative/command ban, an automatic ceasefire system, or protection for claimed land. Other available explosives can still destroy blocks. Use separate military outposts and test defenses away from your main base. Compatibility with this pack's FTB claims and MFFS shields has not been established.

Ballistix's retained explosion cache is disabled to reduce persistent memory use in this large pack. Explosions may need more computation when used; this does not guarantee a lag-free launch or battle. Other Ballistix settings use upstream defaults.

**Update later:** fully exit Minecraft, run the existing **Update CustomATM** shortcut, then launch the CustomATM CurseForge tile. Your friend should do the same before joining. Existing updater version 4 works; no new Setup ZIP is needed. Nothing is applied to a running profile by publishing this release.

Search JEI for `@ballistix` after updating. Start with the launcher platform, matching control panel/support frame, missiles and a conventional explosive. Radar and SAM defenses are available for the opposing outpost. Detailed setup and multiplayer combat still need an in-game test.

Validation: all 578 previous managed entries preserved, two verified author jars and two new policy/config files added. Existing updater suite: 55 checks passed. The real 1.4.0 -> 1.5.0 overlay was installed into an isolated fixture, including jar hashes, repeated update behavior, runtime config expansion, and preservation of world/settings sentinel files. The policy passed tests in the pack's actual Rhino script engine in both callback orders and across reloads. All 12 crafting variants for the eight restricted items are covered. Jars have matching mod IDs/versions, no existing Ballistix/Voltaic ID collisions were found, and Voltaic's declared optional Mekanism version range includes this pack's version.

Minecraft was not launched or closed, and the running profile was not changed. **In-game startup and Essential multiplayer validation remain pending.**

Author downloads: [Ballistix](https://www.curseforge.com/minecraft/mc-mods/ballistix/files/9259921), [Voltaic](https://www.curseforge.com/minecraft/mc-mods/voltaic-api/files/9247107).
