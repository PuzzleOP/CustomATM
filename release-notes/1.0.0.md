CustomATM's first shared client release, based on **ATM10 8.3 / Minecraft 1.21.1 / NeoForge 21.1.259**.

Download **CustomATM-Setup.zip**, extract it, then run **Update Pack.cmd** after installing that base version in CurseForge. Instructions: https://github.com/PuzzleOP/CustomATM/blob/main/FRIEND-SETUP.md

Includes the DynEco broad market, the custom Gamble It shared-wallet bridge, selected Refined Storage addons, Cubes Without Borders, and ten guided quest chapters with 209 quests. Pins 504 mods. Third-party mod downloads come from their original services; only our custom files/bridge are bundled in the overlay.

The updater backs up changed files, checks SHA256 hashes, protects local edits, removes only known obsolete managed files, and recovers interrupted updates. Saved worlds and player progress are untouched. Future updates use the same shortcut.

Validation: 41 automated updater checks passed, including apply/rollback/recovery and personal-file preservation. A separate fresh-install test fetched the added third-party mods from their original URLs and verified all 527 managed files after installation while preserving a test world. Quest data and example-program syntax were checked separately against the installed parsers. Full game startup and multiplayer content testing are still pending. This is a client update package, not a dedicated-server installer.
