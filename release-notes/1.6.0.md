# CustomATM 1.6.0 — Ballistix: Missile Outposts

Adds **11 • Ballistix: Missile Outposts** to the custom guide chapter group: **33 quests**, **24 equipment milestones**, **five practical projects**, **five topic branches** and **four original setup diagrams**.

- Power: an FE battery and cable reference build, correct machine input faces, controller commissioning, handheld-tool charging and a reserve check.
- Missiles: three-piece silo placement, missile/warhead pairing, coordinates, a first controlled launch, accuracy, tiers, frequency and the compact VLS.
- Radar: Search Radar versus Fire Control Radar, siren wiring, Radar Gun linking, friendly-frequency filtering and a detection drill.
- Defenses: SAM and CIWS coverage, laser and railgun alternatives, exact ammunition, player/colony precautions and an interception project.
- Advanced: anti-ballistic silo setup, ESM reconnaissance, remote designators, resupply, troubleshooting and suggested two-player match rules.

The guide uses the pinned Ballistix 1.2.3 / Voltaic 1.2.0 behavior, including FE support without Electrodynamics, bottom inputs on radar/turrets, iron-ingot railgun ammunition, and current radar targeting behavior. Equipment objectives detect inventory without consuming items. Practical projects use explicitly manual confirmations; owning a machine does not prove that it works. Rewards are modest one-time XP. Optional upgrades are not required for the final outpost project.

All previous quests, IDs, mod versions, balance settings and weapon restrictions are preserved. No world or quest-progress data is included in the update. This adds a guide; it does not enable automated battles, new claim protection, or MineColonies allegiance integration.

**Both players:** fully close Minecraft, run the existing **Update CustomATM** shortcut, and launch the CustomATM tile. No new Setup ZIP is needed on updater version 4. Open the quest book and select **11 • Ballistix: Missile Outposts** in the custom guides group. The update also includes Ballistix if you have not yet installed 1.5.0.

Validation: six quest validation tests passed across all 302 custom quests, including unique IDs, resolved/acyclic prerequisites, 209 preserved legacy quest IDs, valid item evidence, language/images, optional paths and bounded rewards. All 22 chapter/language files parse with Minecraft's and FTB's actual parsers without starting a game. An isolated update fixture verifies all 582 prior entries are unchanged and only the new chapter, language file and nine images are added; runtime-rewritten old chapters, world/settings sentinels and quest progress are preserved. The existing 55 updater checks pass. The generated map and diagrams were inspected offline.

Minecraft was not launched or closed and the running profile was not edited. In-game visual layout and multiplayer completion still need a playtest.
