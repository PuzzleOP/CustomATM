# CustomATM 1.2.1 - Casino shortcut and broad-market fixes

- Casino access uses F8 after updating. The updater migrates the conflicting default H and preserves other chosen bindings. New Setup installations now receive F8 even before options.txt exists.
- In Controls, search by key name for **Open Casino**, in the **Casino Mod** category. Press the key while in a world with menus closed. H also opens Essential and conflicts with several ATM10 bindings.
- Fixes the broad DynEco market script failing with a Rhino collection-constructor error. Also fixes its loop retaining the first registry item, so equipment and machines are actually considered while creative/admin items and explicit deny lists remain excluded.

Existing players: close Minecraft, run **Update CustomATM**, then launch CustomATM. No new Setup ZIP is needed for existing installations. Fresh installs should use this release's Setup ZIP.

Validation: 48 updater checks passed, including fresh options, H migration, custom-key preservation and rollback. The market regression test reproduces the old exception using the installed Rhino engine; the corrected script passes inclusion/exclusion and repeat-load checks. Full in-game casino transaction and friend-join testing remain outstanding.
