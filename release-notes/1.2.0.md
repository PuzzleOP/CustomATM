# CustomATM 1.2.0 - Essential invites

Adds **Essential 1.5.1 for Minecraft 1.21.1 / NeoForge** so friends can join a hosted single-player world without setting up a separate server.

- Downloads the official Essential jar from Modrinth, pinned by SHA256. No additional external mod dependencies are declared by this release.
- Removes **Crash Assistant** and **Drippy Loading Screen**, both listed in Essential's official incompatibility guide. The updater backs up both jars; no installed mod declares a required dependency on either one.
- Keeps FancyMenu and the existing gameplay content. The resulting pack contains **503 mod jars**.
- Existing 1.1.0 installations use their normal **Update CustomATM** shortcut; no new Setup download is required. Fresh installs receive this release automatically.

Both players close Minecraft and run the updater, then launch **CustomATM**. Add each other through Essential and use **Host > Start Hosting > Add Members** to invite a friend. The host must keep the world open. [Hosting instructions](https://essential.gg/en/wiki/start-hosting), [compatibility notes](https://essential.gg/wiki/incompatible-mods).

Validation: verified the author's SHA512 and jar integrity; inspected bundled NeoForge metadata; checked required reverse dependencies before removing conflicts; exercised the actual updater download, checksum, transaction backup and removal path. The release changes exactly one addition and two removals from 1.1.0. In-game startup and a two-player invite session still need a playtest.
